Blender アドオン · MMD（PMX / PMD）→ Auto-Rig ProMMD モデルを Auto-Rig Pro のリグに、ワンクリックで。

mmd_tools でモデルを読み込んで、ボタンを1つ押すだけ。骨格に合った Quick Rig のマッピングを自動で選び、目や袖、捩じりなどの MMD の補助ボーンも動くまま残します。

無料で入手 できること
無料・オープンソース 日本語のボーン名のまま VMD モーション対応 Blender 4.5 以降

有償のアドオンが別途必要です。このアドオンは、Auto-Rig Pro と Auto-Rig Pro: Quick Rig（開発元が別途販売）と一緒に使う補助ツールです。無料の mmd_tools も必要です。

できること

Auto-Rig Pro のリグにすると、モーションの使い方が広がります

変換したモデルは、Auto-Rig Pro の機能でそのまま動かせます。

01

VMD 以外のモーションも使える

Auto-Rig Pro の Remap 機能で、Mixamo の FBX やモーションキャプチャーの BVH など、ほかの骨格用のモーションを適用できます。目や袖など、MMD の付与や IK で動く補助ボーンも、モーションについて動きます。

Remap は Auto-Rig Pro の機能です。Mixamo などの T ポーズのモーションは、Remap の「Redefine Rest Pose」で休止姿勢を合わせてから適用します。

Remap の手順（README）
02

モーションを活かして、必要なところだけ IK に

VMD モーションを焼き込んだまま、腕と脚を 1 本ずつ IK に切り替えられます。机に手をつく、段差に足を乗せるといった調整を、その手足だけで行えます。FK に戻せば、元のモーションの動きに戻ります。

焼き込みと IK / FK の切り替え
機能

Quick Rig だけでは手が届かない、MMD 特有の部分を引き受けます

Quick Rig はほとんどの骨格をリグにできますが、MMD モデルではマッピングを手で作る必要があり、変換後には補助ボーンが動かなくなります。その作業を、このアドオンが代わりに行います。

骨格の自動判定背骨、親指、D ボーン、捩じりボーンの構成から、合うマッピングを選びます。
ワンクリックで変換マッピング、Quick Rig の Make Rig、MMD 向けの修正をまとめて実行します。
付与と IK をそのまま「両目」ボーンで動く目、腕を追いかける袖、ハイライトなどが変換後も動きます。
腕の捩じりも自然にMMD と Auto-Rig Pro は捩じりの分担が逆です。ウェイトを入れ替えて、前腕が滑らかに捩じれるようにします。
肘が正しい向きに曲がる休止姿勢で腕がほぼまっすぐなモデルでも、IK の肘が後ろを向くように補正します。
見やすいコントローラー髪やスカート、アクセサリーのボーンは、球の集まりではなく、ボーンに沿った線で表示します。

配布されている MMD モデル 241 体でボーン構造を調べ、構造のパターンごとに代表 36 体で変換結果を確認しています。

2 つのモード

骨格を置き換えるか、残すか

迷ったら Convert から始めてください。

Convert 既定

MMD の骨格を Auto-Rig Pro の骨格に置き換えます。ウェイトも Auto-Rig Pro のボーンに移します。

向いている用途：ゲームエンジンへの書き出し、リターゲットなど、Auto-Rig Pro の機能をすべて使いたいとき。

Preserve

MMD の骨格、付与、補助ボーンを残します。Auto-Rig Pro は MMD の操作用のボーンだけを動かします。VMD モーションと同じ考え方です。

向いている用途：補助ボーンが多く、MMD と同じ変形のまま動かしたいモデル。

モーションと IK / FK

モーションの焼き込みと IK / FK の切り替え

VMD モーションを読み込んであれば、Convert でリグに焼き込みます。そのあと「IK / FK」パネルで、腕と脚ごとにポーズを保ったまま切り替えられます。

  1. モーションを焼き込むモーションは FK コントローラーに入ります。IK-FK スイッチにはキーを打ちません。
  2. 手足を IK に切り替える机に手をつく、段差に足を乗せるなど。その手足は VMD の影響を受けなくなります。
  3. FK に戻すVMD のモーションどおりの動きに戻ります。自動キー挿入が ON なら、スイッチのキーを混ざらない形で打ちます。
FK（VMD）IKFK（VMD）
フレーム 1100150

例：フレーム 100 で左手を IK に、フレーム 150 で FK に戻すと、フレーム 100〜149 だけが IK の手になります。

FAQ

よくある質問

Auto-Rig Pro がなくても使えますか？

使えません。変換そのものは Auto-Rig Pro: Quick Rig が行い、Quick Rig には Auto-Rig Pro が必要です。どちらも開発元が別途販売している有償のアドオンです。このアドオンは無料で、MMD 特有の部分を補います。

自分のモデルでも使えますか？

一般的な MMD の骨格（標準ボーンと準標準ボーン）のモデルに対応しています。背骨、親指、D ボーン、捩じりボーンの構成を判定して、合うマッピングを選びます。

補助ボーンを独自の仕組みで動かすモデルの中には、mmd_tools でも MMD と同じには動かないものがあります。変換後のリグは mmd_tools での動きを再現するので、MMD での見た目とは異なる場合があります。判定時にパネルに注意が表示されます。

ボーン名を英語にする必要はありますか？

ありません。日本語のボーン名と、mmd_tools の既定のインポート設定のままで使ってください。VMD モーションもそのまま読み込めます。

再現されないものはありますか？
  • 物理演算（剛体とジョイント）
  • Convert では、付与親が捩じりボーン（腕捩、手捩など）である付与（そのようなモデルは Preserve を使ってください）
  • Preserve では、割り当てたボーンを含む MMD の IK（髪の IK など）
モデルを変換してもよいのでしょうか？

このアドオンは、モデルやモーションに関する権利を与えるものではありません。改変や他のソフトウェアでの利用、作ったものの公開ができるかどうかは、各モデル・モーションの利用規約で決まります。変換する前に確認してください。

うまくいかないときは？

README のよくある質問・トラブルを確認してください。解決しない場合は、GitHub Issues で報告してください。モデルやモーションのファイルは添付せず、ボーンの名前と親子関係を書いてください。
