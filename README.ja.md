# MMD to Auto-Rig Pro

[English](README.md) | 日本語 | サイト：https://mmd-to-arp.utage.studio/ja/

MMD モデルを Auto-Rig Pro のリグに変換する Blender アドオンです。

- mmd_tools で読み込んだ MMD モデル（PMX / PMD）が対象です。
- 変換そのものは Auto-Rig Pro: Quick Rig が行います。
- このアドオンは、モデルの骨格に合ったマッピングを自動で選びます。
- MMD 特有の仕組み（付与や IK で動く補助ボーン）も、変換後に自動で修正します。
- 241 体の配布モデルでボーン構造を調べ、構造のパターンごとに代表 36 体で変換結果を確認しています。

## 必要なもの

| ソフトウェア | 動作確認バージョン |
|---|---|
| Blender 4.5 以降 | 4.5, 5.3 |
| [mmd_tools](https://extensions.blender.org/add-ons/mmd-tools/) | 拡張機能版 |
| [Auto-Rig Pro](https://lucky3d.fr/auto-rig-pro/)（有償） | 3.79 |
| Auto-Rig Pro: Quick Rig（有償） | 1.28 |

- 上の 3 つのアドオンを、インストールして有効にしておいてください。
- Auto-Rig Pro と Quick Rig は、動作確認したバージョン以外でも使えることがあります。その場合は、パネルに小さく注意が表示されます。

## インストール

### リポジトリを追加する（おすすめ、自動で更新）

1. Blender で「編集 > プリファレンス」を開き、「Get Extensions」を選びます。
2. 右上の「Repositories」で「+」を押し、「Add Remote Repository」を選びます。
3. 次の URL を入力します：`https://mmd-to-arp.utage.studio/repository/index.json`
4. 「MMD to Auto-Rig Pro」を検索して、「Install」を押します。

新しいバージョンが出ると、Blender の更新として表示されます。

### zip ファイルからインストールする

1. [Releases](https://github.com/utagestudio/mmd_to_arp/releases) から zip ファイル（`mmd_to_arp-<バージョン>.zip`）をダウンロードします。zip は解凍しないでください。
2. Blender で「編集 > プリファレンス」を開き、「Get Extensions」を選びます。
3. 右上のメニューから「Install from Disk」を選び、zip ファイルを選びます。
   - zip ファイルを Blender の画面にドラッグ＆ドロップしても、インストールできます。

## 使い方

1. mmd_tools で PMX / PMD ファイルをインポートします。
   - 「ボーン名の変換（Rename Bones - L / R Suffix）」は ON のままにしてください。これが既定値です。
   - 「Use Underscore」と、辞書による英語への変換は使わないでください。
2. モデルを選択します。ルート、アーマチュア、メッシュのどれを選んでも構いません。
3. 3D ビューのサイドバーで「**MMD ARP**」タブを開きます。
4. **Mode** を選びます。迷ったら Convert を選んでください。
5. 「**Detect Preset**」を押すと、判定結果と注意事項を確認できます。この手順は省略できます。
6. 「**Convert to Auto-Rig Pro**」を押します。マッピングの設定、Quick Rig の Make Rig、変換後の修正をまとめて実行します。

### Mode

| Mode | 内容 | 向いている用途 |
|---|---|---|
| Convert | MMD の骨格を Auto-Rig Pro の骨格に置き換えます。ウェイトも Auto-Rig Pro のボーンに移します。 | Auto-Rig Pro の機能をすべて使いたいとき。ゲームエンジンへの書き出しやリターゲットなど。 |
| Preserve | MMD の骨格、付与、補助ボーンを残します。MMD の操作用のボーンだけを Auto-Rig Pro で動かします。VMD と同じ考え方です。 | 補助ボーンの多いモデルを、元の変形のまま動かしたいとき。 |

### オプション

- **Preset**：「Auto」以外を選ぶと、判定を使わずに、選んだマッピングで変換します。
- **Arms / Legs**：生成するリグの腕と脚を、IK と FK のどちらで始めるかを選びます。既定値は Quick Rig と同じで、腕が FK、脚が IK です。
- **Other Bones**：腕、脚、体幹以外のボーン（髪、スカート、アクセサリーなど）のコントローラーの形です。
  - **Line**（既定値）：ボーンに沿った線です。ボーンのつながりが分かりやすくなります。
  - **Sphere** / **Box**：Quick Rig 標準の球と箱です。
- **Bake Motion**：MMD のアーマチュアにモーション（VMD）があるときに表示されます。
  - モーションを、リグの腕と脚の FK コントローラーに焼き込みます。
  - IK-FK スイッチにはキーを打ちません。そのため、モーションの途中で IK に切り替えられます。
  - 焼き込みのあと、ルートの動きをフレームごとに補正します。進み具合はサイドバーに表示されます。数千フレームのモーションで、1 分ほどかかります。
  - Esc か「Stop」で、補正を止められます。それまでに補正したフレームは残ります。取り消し（Ctrl+Z）で補正前のリグに戻り、もう一度取り消すと Convert の前に戻ります。

## IK / FK の切り替え

リグを選ぶと、サイドバーに「**IK / FK**」パネルが表示されます。リグで変形するメッシュを選んでも表示されます。

- 腕と脚を、左右ごとに IK / FK に切り替えられます。「All」で、すべてをまとめて切り替えることもできます。
- ボーンを選択する必要はありません。
- Auto-Rig Pro の「Snap IK-FK」と同じ処理です。ポーズを保ったまま切り替わります。
- 自動キー挿入が ON のときは、キーも打たれます。

### モーションを焼き込んだリグの場合

- IK に切り替えると、手や足を好きな位置に置けます。このとき、その腕や脚は VMD の影響を受けません。
- FK に戻すと、VMD のモーションどおりの動きに戻ります。
- 自動キー挿入が ON のときは、IK-FK スイッチのキーを「一定」の補間で打ちます。そのため、キーとキーの間で IK と FK が混ざりません。
  - 例：フレーム 100 で IK、フレーム 150 で FK に切り替えると、フレーム 100〜149 だけが IK になります。
  - 最初のキーより前のフレームも、最初のキーの値になります。それより前を FK にしたいときは、手前のフレームでも FK に切り替えてください。

### 注意

FK の肘と膝は、Z 軸まわりにしか曲がらないようにロックされています。ロックを外して別の軸で曲げたポーズは、IK では再現できません。そのため、切り替えると腕の捩じれが変わります。

## 腕の IK の向き

Quick Rig は、肘の IK ポールの位置を、腕のボーンのロールから決めます。そのため、一部の MMD モデルでは、IK で腕が逆向きに曲がることがあります。休止姿勢で腕がほぼまっすぐなモデルや、肘がわずかに前へ曲がっているモデルです。

このアドオンは、肘がはっきり後ろへ曲がっていない腕を見つけて、Quick Rig の「Auto-Elbow Direction」（Force Straight Direction）を有効にしてから変換します。このとき、肘の関節の位置が、肩と手首を結ぶ線の上に移動します。移動量は多くの場合数 mm で、確認したモデルでは最大約 1 cm でした。

## ほかのモーションを使う（Auto-Rig Pro の Remap）

変換したモデルは、Auto-Rig Pro のリグになります。Auto-Rig Pro の Remap 機能で、Mixamo の FBX やモーションキャプチャーの BVH など、ほかの骨格用のモーションを適用できます。

- Convert で変換したリグと、Mixamo のモーションで確認しています。

MMD モデルの休止姿勢は A ポーズで、上腕が約 40° 下を向いています。Mixamo など、多くのモーションは T ポーズ用です。先にモーションの休止姿勢をリグに合わせてください。合わせないと、腕が回りすぎて、手が背中の後ろに回ります。

1. Auto-Rig Pro の Remap パネルを開きます。モーションのあるアーマチュアを Source に、リグを Target にします。
2. 「Build Bones List」を押します。
3. 「Mapping Presets」で、Source に合うプリセットを読み込みます。Mixamo なら、腕と脚が FK の Mixamo のプリセットを使います。
4. 「Redefine Rest Pose」を押します。
5. Source の腕のボーン（上腕、前腕、手）を選びます。
6. 「Copy Selected Bones Rotation」を押します。選んだボーンが、リグのボーンと同じ向きになります。
7. 「Apply」を押します。
8. 「Re-Target」を押します。

脚の向きも違う場合は、手順 5〜6 で脚も合わせてください。

## 手順を分けて実行する

サイドバーの「Step by Step」から、各手順を個別に実行できます。

1. **Load Mapping to Quick Rig**：マッピングを Quick Rig に読み込みます。Quick Rig の画面で内容を確認し、修正できます。
2. Quick Rig の「Make Rig!」を実行します。
3. 生成されたリグを選択して、**Run Post-Fix** を押します。Convert と Preserve のどちらで作ったリグかは、自動で判別します。

## 変換後の修正の内容

### Convert

Quick Rig は、割り当てていないボーンのコンストレイントをコピーしません。そのため、MMD の IK や付与で動くボーンが動かなくなります。このアドオンは、次の 2 つをリグに復元します。

- **IK**：腕などを追いかける補助ボーン（袖など）の IK を作り直します。
- **付与**：「両目」ボーンで両目を動かす仕組み、ハイライト、「肩C」などの付与を作り直します。mmd_tools と同じ仕組みで設定します。
  - IK で太ももの向きを取り出し、付与で太ももの補助ボーンを動かす仕組み（膝捩など）も、IK と付与の両方を作り直して再現します。
- **モーション**：モーションを焼き込んだ場合、IK や付与で動くボーンには VMD の元のキーを使います。焼き込まれた最終的な姿勢のキーを使うと、IK や付与の効果が二重にかかるためです。

### Preserve

Quick Rig は、元の骨格のすべてのボーンを Auto-Rig Pro に拘束します。そのため、D ボーンや捩じりボーンの付与が上書きされます。このアドオンは、次のように修正します。

- 割り当てたボーンを含む MMD の IK（足ＩＫ、つま先ＩＫなど）をミュートします。
- 付与や IK で動くボーンから Quick Rig の拘束を外し、モデル本来の仕組みで動かします。
- 髪やスカートなど、素直にぶら下がるボーンは、Auto-Rig Pro のコントローラーで動かせるまま残します。

### 共通

モーションを焼き込んだリグでは、IK-FK スイッチのキーを削除します。Quick Rig の Make Rig で焼き込んだリグも対象です。

## よくある質問・トラブル

**パネルに「Required add-ons not enabled」と表示される**
- 表示されているアドオン（mmd_tools、Auto-Rig Pro、Auto-Rig Pro: Quick Rig）を有効にしてください。

**パネルに「untested」と表示される**
- インストールされている Auto-Rig Pro または Quick Rig が、動作を確認していないバージョンです。
- そのまま使えることが多いですが、うまく変換できない場合は、動作確認済みのバージョン（「必要なもの」を参照）と比べてください。

**判定されたプリセットがおかしい、腕や脚がずれる**
- mmd_tools のインポート設定を確認してください。「ボーン名の変換（Rename Bones - L / R Suffix）」が ON で、「Use Underscore」と英語への変換が OFF である必要があります。
- **Preset** で別のプリセットを選んで、変換し直してください。
- 「Step by Step」の **Load Mapping to Quick Rig** で読み込んだあと、Quick Rig の画面でボーンの割り当てを直すこともできます。

**変換後、一部のメッシュ（袖、装飾、補助ボーンで動く部分）が正しく動かない**
- **Preserve** で変換し直してください。Preserve は、モデル本来の補助ボーンの仕組みを残します。
- 判定時に「helper-bone system that mmd_tools cannot reproduce」と表示されたモデルは、どちらの Mode でも正しく変形しません。

**IK にすると腕が逆向きに曲がる**
- 0.2.0 より前のバージョンで変換したリグでは、この問題が起きることがあります。最新のバージョンで変換し直してください。
- それでも起きる場合は、肘の IK ポール（c_arms_pole）の位置を動かしてください。

**変換をやり直したい**
- Ctrl+Z で変換前に戻せます。うまく戻らない場合は、モデルを読み込み直してください。

**「Bake Motion」が表示されない**
- MMD のアーマチュアにモーションがありません。モデルを選択し、mmd_tools でモーション（VMD）を読み込んでから変換してください。

**モーションを焼き込んだリグで、FK に戻すと手足が元の動きに戻る**
- 仕様です。焼き込んだモーションは FK コントローラーにあります。手足を自由に動かしたい区間だけ IK に切り替えてください（「IK / FK の切り替え」を参照）。

**Make Rig の「Copy Constraints」を ON にしたら壊れた**
- 「Copy Constraints」は mmd_tools の内部ボーンを壊すので、OFF のまま使ってください。MMD の IK と付与は、変換後の修正で復元します。

## 制限事項

- 付与親が捩じりボーン（腕捩、手捩など）の場合、Convert ではその付与が失われます。補助ボーンは、親ボーンについて動くだけになります。MMD と Auto-Rig Pro では捩じりの分担が違うためです。気になる場合は Preserve を使ってください。腕や脚などのほかの割り当てたボーンが付与親の場合は、復元します。
- Make Rig の「Copy Constraints」は ON にしないでください。mmd_tools の内部ボーンが壊れます。
- 補助ボーンを独自の仕組みで動かすモデルの中には、mmd_tools でも MMD と同じには動かないものがあります。変換後のリグは mmd_tools での動きを再現するので、MMD での見た目とは異なる場合があります。判定時に注意を表示します。
- Preserve では、割り当てたボーンを含む MMD の IK をミュートします。そのため、髪の IK などは使えなくなります。髪は Auto-Rig Pro のコントローラーで動かしてください。
- 腕捩ボーンが無い古いモデルでは、Convert で上腕を捩じっても、上腕は捩じれません。曲げは問題ありません。
- 物理演算（剛体とジョイント）は再現されません。

## アドオンを使わずにプリセットだけ使う

`presets/` フォルダのファイルは、Quick Rig のプリセットとしてそのまま使えます。

1. `presets/*.py` を Quick Rig のプリセットフォルダ（Custom Presets Path）にコピーし、Blender を再起動します。
   - 既定のフォルダは `~/Documents/AutoRigPro/Quick Rig Presets/` です。
2. 使うプリセットは、`mmd_to_arp/detect.py` で調べられます。モデルをインポートしたあと、このファイルをテキストエディタで開いて「Run Script」を実行してください。
3. Convert 用のプリセット（`MMD_*`）は Convert モードで、Preserve 用のプリセット（`MMD_P_*`）は Preserve モードで、Make Rig を実行します。
   - Convert 用のプリセットを Preserve モードで使う場合は、「Constrain Overrides」を ON にしてください。
4. 生成されたリグを選択し、次のファイルをテキストエディタで開いて「Run Script」を実行します。
   - Convert の場合：`mmd_to_arp/fix_convert.py`
   - Preserve の場合：`mmd_to_arp/fix_preserve.py`（必須です）

プリセットの一覧とマッピングの設計は、[docs/presets.md](docs/presets.md) を参照してください。
